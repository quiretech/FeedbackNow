FRMPayload schema — must match downlink_dispatch.c
Byte 0 = command. · 0x01 + uint32 BE epoch (5 B). · 0x02 (1 B). · 0x03 + int16 BE tz minutes (3 B). · 0x04–0x08 single-byte cmds (1 B each). · 0x99 + dur (u8 min; 0 = default 5 min) + body: each message byte becomes two ASCII hex digits (0-9A-Fa-f); firmware decodes to printable 0x20–0x7E (rejects decoded NUL).
Downlink air cap in firmware: LORA_MAX_DOWNLINK_FRMPAYLOAD_SIZE = 51 B (raise in sys_config.h if your MAC allows longer). Device accepts any LoRaWAN downlink FPort the stack delivers (AWS CLI example uses FPort=1 — align with your device profile).
